# Pattern Generator and Number Analyzer

## 📌 About the Project

This is a simple Python project for beginners.
It can create different star patterns and analyze numbers in a given range.

## ✨ Features

1. Right-angled Triangle
2. Pyramid
3. Left-angled Triangle
4. Check numbers as Even or Odd
5. Find the sum of numbers in a range
6. Exit the program

## 🛠️ Requirements

* Python 3.x

## ▶️ How to Run

1. Install Python.
2. Open the project folder.
3. Run the Python file:

```bash
python pattern_generator.py
```
